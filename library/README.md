# Seed library

Twenty curated games are ready for offline demos.
The first ten cover distinct mechanics. The remaining ten demonstrate other allowed verbs.
Each game is a plain spec JSON file. Its sibling receipt records actual independent
40 seed bot results and a difficulty summary.

The source text names the verified main build thread.
threadId, model, durationMs, playtests and token usage are null because these were written
during the build, not generated by separate runtime factory jobs.
Validation reports are real harness results.

npm run library:seed regenerates these files from the canonical examples.
It reads the main thread ID from the supplied SESSION_ID.txt file, or the explicitly
configured CODEX_BUILD_THREAD_ID. The command refuses an invalid ID.
npm test checks all twenty through fresh server validation.
